# Enquiry page photos

Every JPG / PNG / WebP / AVIF image in this folder appears in the moving
"garment rail" on the public enquiry page (`/enquiry`), in file-name order.

- Name files to set the order and the description, e.g.
  `01-red-bridal-lehenga.jpg`, `02-ivory-anarkali.jpg`, `03-sherwani.jpg`
  (the alt text becomes "Red bridal lehenga by Needleye").
- Portrait photos work best (3:4). Around 1200 px tall is plenty; keep each
  under ~400 KB (the site serves resized copies, but smaller originals deploy faster).
- 6-12 photos look good. With none, the page shows fabric swatches instead.
- Commit and redeploy the web app to publish new photos.

The current photos are Needleye's own pieces on its studio mannequins, taken
from the previous website. Use only photos of Needleye's own work (not stock
or models from photo libraries).
